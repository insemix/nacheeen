Calculadora de IVA

Escribe un importe, elige el tipo de IVA y obtén la base, la cuota de IVA y el total al momento.

Cómo calcular el IVA

El IVA (Impuesto al Valor Agregado o Añadido) se calcula como un porcentaje sobre la base imponible, que es el precio del producto o servicio antes de impuestos.

Añadir IVA a un precio

Total = Base × (1 + tipo / 100). Por ejemplo, con una base de 100 y un IVA del 21%: 100 × 1,21 = 121. La cuota de IVA es 21.

Quitar el IVA de un precio (desglosar)

Base = Total ÷ (1 + tipo / 100). Un error frecuente es restar el 21% al total: si un producto cuesta 121 con IVA, la base no es 121 − 21% (95,59), sino 121 ÷ 1,21 = 100.

Tipos de IVA por país

Los tipos generales de la lista son orientativos. Muchos países aplican además tipos reducidos para alimentos, medicinas o libros. Antes de facturar, confirma siempre el tipo vigente con la autoridad tributaria de tu país.

Preguntas frecuentes

¿Cómo saco el IVA de un precio que ya lo incluye?

Divide el precio entre 1 más el tipo expresado en decimal. Con un IVA del 16%: precio ÷ 1,16. El resultado es la base, y la diferencia con el total es el IVA.

¿Por qué no puedo restar directamente el porcentaje?

Porque el IVA se calcula sobre la base y no sobre el total. Si restas el porcentaje al total, le estás aplicando el porcentaje a una cantidad mayor y la base sale más baja de lo que es.

¿Esta calculadora guarda mis datos?

No. Todos los cálculos se hacen en tu navegador y no se envía nada a ningún servidor.
